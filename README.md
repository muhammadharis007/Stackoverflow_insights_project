# Stack Overflow Developer Survey Insights

This project analyzes the 2025 Stack Overflow Developer Survey results to extract insights about developer demographics, compensation, technology trends, and job satisfaction.

## Project Structure

- `data/`: Contains the raw and processed survey data.
  - `raw/`: Original, unmodified data from the survey.
  - `processed/`: Cleaned and feature-engineered data.
- `notebooks/`: Jupyter notebooks for analysis. The notebooks are numbered in the order they should be run.
- `results/`: Output from the analysis, including tables and visualizations.
  - `tables/`: CSV files with summary statistics and analysis results.
  - `visualizations/`: Plots and charts generated during the analysis.
- `reports/`: Text-based reports and summaries.
- `docs/`: Project documentation.

## How to Run

1.  Install the required packages: `pip install -r requirements.txt`
2.  Run the notebooks in the `notebooks/` directory in numerical order.
